
## A Simple Python CLI Password Generator.

---

### Features:
- Generate secure passwords with customizable length and complexity.
- Write to local .txt file.
- Zero dependencies, runs with standard Python library.
- Cross-platform compatibility (Windows, macOS, Linux).

### Usage:
1. Clone the repository or download the `GenMe.py` file.
2. `python3 GenMe.py`
3. Follow the prompts.
4. Your password will be saved with the purpose you gave it.
5. It will also print to STDOUT.
